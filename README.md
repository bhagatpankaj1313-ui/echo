# Echo

A turn-based puzzle game with a twist: **cooperate with your past selves**. Record your route, rewind time, and your echo replays it beside you — holding switches, opening color-coded gates, and grabbing fragments your present self can't reach.

## Play it
- Open `index.html` in any modern browser, or
- Enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main`) for a live playable link.

## Features
- 12 handcrafted loops introducing layered echo mechanics: anchors, detours, nested locks, chorus switches, timing windows
- Record / rewind / undo-beat system with full state snapshots
- Color-coded switch-and-gate circuits (cyan, amber, chorus)
- Signal fragments, particle effects, synthesized sound
- Keyboard (arrows/WASD, Space to record), swipe, and on-screen touch controls
- Level select archive with completion tracking, light/dark mode

## Tech
Single self-contained HTML file. Vanilla JS + Canvas 2D rendering, Web Audio API for sound. Zero frameworks.

Built with Muse (Meta's personal AI agent).
